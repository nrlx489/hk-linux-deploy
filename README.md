## 为什么是香港，而不是美国或日本

把香港和美国、日本放一起比较，结论会清晰很多。

- **延迟**：香港到大陆的Ping值通常在30-80ms，日本东京大约80-120ms，美国西海岸则在150-250ms。如果你的主要用户在大陆或东南亚，香港的物理距离优势直接体现在首字节响应上。
- **备案**：香港、美国、日本都免ICP备案，但香港在合规边界上更接近大陆习惯，对内容审查的尺度也相对宽松，适合需要快速上线又不想踩线的业务。
- **国际出口**：香港接入HKIX本地交换，同时直连电信CN2、移动CMI、联通骨干网，海外访问和回国访问都不算短板。美国节点回国延迟高，日本节点国际出口稳定但回国线路选择不如香港丰富。

简单说：业务面向亚太、对延迟敏感、又想绕开备案，香港几乎是默认选项。如果你的用户主要在欧美，那美国节点更合适，本文不展开。

## Linux还是Windows：香港服务器上的系统选择

很多人在选香港服务器时纠结系统，其实答案比想象中明确。

Linux在服务器领域几乎是默认选项，原因很实际：

- **开源免费**，不需要额外支付授权费。Windows Server授权按核心计费，长期下来是一笔不小的成本。
- **资源占用低**，同样1核1G的配置，Linux能跑的服务比Windows多。入门级套餐选Linux更划算。
- **生态完整**，Nginx、MySQL、Docker、宝塔面板、各种开发语言运行环境，Linux上的部署文档和社区支持远超Windows。
- **远程管理**用SSH即可，轻量高效；Windows需要RDP，对带宽和资源占用更高。

Windows Server更适合必须使用.NET、ASP.NET、MSSQL或某些Windows专属软件的场景。恒创科技支持CentOS、Ubuntu、Debian等主流Linux发行版，也支持Windows Server 2012/2016/2019/2022，但Windows授权需额外付费，且2核2G以下配置不建议装Windows。

如果你没有明确的Windows依赖，选Linux就对了。

## 香港Linux服务器的典型用途

把用途想清楚，配置和预算才好定。

- **外贸独立站/企业官网**：面向海外客户展示，WordPress、Magento、Shopify自建站都很常见。1核1G到2核2G基本够用。
- **跨境电商后台**：订单管理、库存同步、ERP对接，并发不高但要求稳定。2核4G起步比较稳妥。
- **API服务/中转节点**：面向亚太用户的接口服务，或作为大陆与海外之间的数据中转。对带宽和延迟敏感，建议选CN2线路。
- **开发测试/CI环境**：团队远程协作、自动化构建、镜像仓库。云服务器按需升降配比物理机灵活。
- **游戏私服/小型游戏后端**：对单核性能和网络稳定性要求高，物理服务器或高主频云服务器更合适。
- **SEO站群**：需要大量独立IP避免搜索引擎关联识别，站群服务器是专门为此设计的。
- **视频/下载站**：流量大，普通带宽扛不住，需要大带宽服务器（50M-10G）。

把用途和下面的配置对应起来，选型会快很多。

## CN2 GIA和其他线路的区别

香港服务器的网络质量很大程度上取决于接入线路，这也是恒创科技反复强调CN2 GIA的原因。

- **CN2 GIA**：中国电信下一代承载网，双向全程CN2，QoS级别高，高峰时段也不容易拥堵。大陆电信用户访问延迟通常在30-50ms，是回国访问体验最好的线路之一。恒创的CN2 GIA是双向全程，不是某些友商的半程或单向CN2。
- **BGP精品线路**：多线自动调度，电信、联通、移动都覆盖，适合三网用户混合访问的场景。恒创香港一区仅提供BGP精品线路。
- **BGP优化/国际/高防**：香港二区提供这几种线路，优化线路针对大陆访问调优，国际线路针对海外访问，高防线路带DDoS防护。

选线路的逻辑：用户主要在大陆，优先CN2 GIA或BGP精品；用户主要在海外，国际线路更合适；有攻击风险，选高防线路。如果你不确定用户分布，BGP精品是最稳妥的默认选项。

"免备案"是香港服务器最常被提起的优势，但有几个细节值得说清楚。

简单说，免备案解决的是"快速上线"的问题，不解决"内容合规"的问题。

## 部署Linux服务器的实际流程

买完服务器之后到业务上线，中间还有几步。

1. **选择镜像**：恒创控制台提供CentOS、Ubuntu、Debian等Linux发行版镜像。Ubuntu对新手友好，文档多；CentOS系（包括Rocky/AlmaLinux）在企业环境常见；Debian轻量稳定。2核2G以下配置不建议选Windows。
2. **配置安全组**：开通时必须修改默认远程端口，恒创强制要求这一步。同时配置防火墙规则，只开放必要端口（SSH、HTTP、HTTPS等）。
3. **SSH连接**：拿到IP、用户名（默认root或自定义）、自动生成的密码后，用SSH客户端连接。建议首次登录后立即修改密码并配置密钥登录。
4. **安装运行环境**：可以手动装Nginx/MySQL/PHP，也可以用宝塔面板（恒创支持宝塔）一键部署。宝塔对新手友好，但会占用额外资源，1核1G配置建议手动精简安装。
5. **部署业务**：上传代码、配置数据库、绑定域名、申请SSL证书（Let's Encrypt免费）。恒创提供免费数据迁移服务，技术团队可协助从其他服务器迁移数据。
6. **监控与维护**：恒创大部分服务器带IPMI接口，可远程管理电源、查看流量监控图。小部分未配置IPMI的机型需提交工单获取流量数据。

整个过程从开通到上线，熟练的话一两个小时，新手可能需要半天到一天。
